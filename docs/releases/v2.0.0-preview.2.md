**First preview of JSeek（简搜）2.0** — the cross-platform successor to JMacEverything, for macOS and Windows.

> ⚠️ Preview build: unsigned, not yet tested on many machines. Please report problems in Issues.

### What's in it
- The same search engine as 1.9 (≈12,000 tests passing on macOS, Windows and Linux), with the full query syntax: `ext:pdf;docx`, `size:>100mb`, `dm:thisweek`, `path:Downloads`, `parent:`, `folder:`, AND / OR / `!`, `"exact"`.
- New interface: numbered tabs (⌘/Ctrl 1–9), QUICK chips (⌃⌥1–9), start panel, file rows and content-match rows with line numbers.
- Content search: find text inside files (choose which file types in Settings).
- Settings page: every tab's extension list, QUICK chips, content file types, folder to index, 5 color cards, light/dark, language (简体中文 / 繁體中文 / English / 日本語).
- Stays in the menu bar / tray; global shortcut (⌥Space on Mac, Ctrl+Alt+Space on Windows); optional launch at login.

### First launch
- **Mac:** right-click JSeek → **Open** (the app is not signed yet). To index the whole disk, allow JSeek in System Settings → Privacy & Security → **Full Disk Access**.
- **Windows:** if SmartScreen warns, choose **More info → Run anyway**.

### Known limitations
- Windows still uses a slow directory walk; the fast NTFS (MFT/USN) indexer comes in M4.
- The index refreshes on launch and via “Rebuild index”; live file-change updates come later.

**简搜 2.0 首个预览版**：JMacEverything 的跨平台版本，支持 macOS 和 Windows。

- 与 1.9 相同的搜索引擎和全部查询语法；全新界面：顶栏标签、QUICK 快捷词、起始页、内容搜索。
- 设置页可修改所有扩展名清单、快捷词、索引文件夹、5 套色卡、深浅色和语言（简中 / 繁中 / 英 / 日）。
- 常驻菜单栏 / 托盘，全局快捷键（Mac ⌥Space，Windows Ctrl+Alt+Space），可开机自启。
- **首次打开：** Mac 右键 → 打开，并在「隐私与安全性 → 完全磁盘访问权限」里允许 JSeek；Windows 若出现 SmartScreen 提示，点「更多信息 → 仍要运行」。
- **已知限制：** Windows 目前用普通遍历建索引，较慢；基于 MFT/USN 的秒级索引在 M4 加入。
